# Grupo-de-IT

Objetivos grupo de IT:
- Entrar en la dark web y buscar leaks del gobierno y foros de hacking.
- Aprender a usar la terminal de Linux.
- Reclutar más gente.

Objetivos avanzados:
- Participar en un hackathon.
- Hacer un podcast.
- Hacer una minishell.

Objetivo ultra-avanzado:
- Descubrir algo y realizar una denuncia formal.
